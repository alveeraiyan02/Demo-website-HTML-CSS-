☕ Bean Boutique Coffee House BD

A multi-page front-end web application for Bean Boutique, a specialty coffee house and brewing equipment store based in Dhaka, Bangladesh. Built using pure HTML5 and CSS3.

📋 Overview

Bean Boutique is a six-page website designed to showcase specialty coffee drinks, home brewing equipment, hands-on coffee workshops, and membership discounts. Visitors can explore the menu with prices in Bangladeshi Taka (৳), register for upcoming coffee events, find the cafe's location on an embedded Google Map, and navigate seamlessly across all sections.

✨ Pages & Features

Home (Home.html) — Welcomes visitors to Bean Boutique with a hero banner, quick order call-to-action, embedded Google Maps location (Daffodil International Academy area, Dhaka), opening hours (8:00 AM – 8:00 PM, Sunday–Friday), and an upcoming events preview.

Coffee Choice (Coffee.html) — Displays the cafe's coffee menu with descriptions and pricing:

Espresso Shots (৳250)

Americano Coffee (৳350)

Latte (৳400)

Mocha (৳450)

Flat White (৳500)

Hazelnut Coffee (৳500)

Brewing Equipment (BrewEquip.html) — Product catalog for home brewing gear:

Coffee Filter (৳1,200)

Kettle (৳1,500)

French Press (৳3,500)

Coffee Grinder (৳4,000)

Events & Workshops (Workshop.html) — Showcases scheduled community events (Coffee Making Workshop, Coffee Bean Roasting, and Meet & Greet) along with an interactive HTML registration form.

Offers & Discounts (Offers.html) — Highlights Bean Boutique Coffee Club membership perks, including 15% OFF all brewing equipment and 10% OFF all coffee blends.

Shopping Cart (Cart.html) — Dedicated cart placeholder page indicating upcoming checkout functionality.

🛠️ Technologies Used

HTML5 — Semantic structure, navigation bars, interactive registration forms, and Google Maps <iframe> integration.

CSS3 — Custom layout styling, product cards, buttons, and typography (Css/stylesheet.css).

🚀 How to Run Locally

Clone or download this repository:

git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git


Open the project folder and launch Home.html in any modern web browser (Chrome, Edge, Firefox, or Safari).

Tip before publishing on GitHub Pages: In Coffee.html, the "Order Now" links currently point to cart.html (lowercase), while the file is named Cart.html (capitalized). Since GitHub Pages is case-sensitive, updating those links to Cart.html ensures they work smoothly online!
